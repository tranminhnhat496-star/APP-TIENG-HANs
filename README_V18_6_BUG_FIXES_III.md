- **Evidence:** the V40 C-02 fix added `checkPhase()` to `castSkillInFight` (`src/v23.js`). F.caMode : F.qmode` with NO fallback, `caMode` is undefined on the first CA, and a grammar `cur` has no `optsVi` → `TypeError: Cannot read properties of undefined (reading 'findIndex')`, buttons dead until the 15 s CA timer expired. Node vm proof on the V18.5 base (test41 §41A run against the pre-fix logic): in-flight answer counted (`caRight` 1 after it), perfect run resolved 0/3.
- **Fix (4 build replacements, `R-V41-V19-CA-ANSWER` + `R-V41-V19-CA-PICK` + `R-V41-V19-CA-PCPW` + `R-V41-V19-CA-CLAMP`):** in `answer()`, `pick()`, `pickCorrect()` and `pickWrong()` (`src/v19.js`), take the CA path ONLY when the current question IS a CA question — `F.qmode` starts with `'ca-'` (mirroring the safe fallback `qHTML` already uses: `F.ultActive ? ### 2. F1 (MINOR, save/import) — boot threw on a save without `S.opt`, `#app` stayed empty

- **Evidence:** `load()` (`index.html:925-926`) returns a parsed save as-is when it has `cards`, never defaulting `opt`. `startSession` (`index.html:953`, called from boot `:1322`) reads `S.opt.group` → uncaught `TypeError: Cannot read properties of undefined (reading 'group')` on every boot of such a save; `#app` stays empty. Node vm proof on the V18.5 base: no-opt save → load error, `#app` length 0.
- **Fix (1 build replacement, `R-V41-LOAD-OPT`):** in `load()`, default it — `if(!j.opt) j.opt={mode:'card',dir:'kv',group:'',due:false}`. This covers both boot and validated import (both go through `load()`).
- **Verified:** Node suite §41C — fresh ctx seeded with a no-opt save (5 KO cards): all inline scripts evaluate without error, study view renders into `#app`, `S.opt` defaulted to `{mode:'card',dir:'kv',group:'',due:false}`, cards preserved; `validateSave` accepts a no-opt save. **Painted-boot gate pending** (repro F1 + verify V41-B) — Chrome dead at build time.
