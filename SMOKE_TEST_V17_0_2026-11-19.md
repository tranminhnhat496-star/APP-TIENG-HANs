## 2. Bugs found during the build

- **B-33-1 (PRODUCT BUG — quest completion had no accuracy
  threshold, found by `test33.js` §4):** `checkCompletions()`
  (`src/v33.js`) marked a quest done whenever any matching en27
  session existed, regardless of accuracy. Repro (Node vm, real
  V27 engine): start `q_gear`, drive a real session to 12 correct /
  4 wrong (acc 0.75) — `questState('q_gear')` returned `'done'`
  and `claimQuest` paid +20 XP, although the overlay promises
  “≥ 80%”. Root cause: the quest branch never compared `hit.acc`
  to a threshold (the rift branch records best accuracy, so it was
  unaffected). **FIXED 2026-11-19 (rebuild):** new constant
  `QUEST_MIN_ACC=0.8`; the quest branch marks done only when
  `hit.acc >= QUEST_MIN_ACC`. A below-threshold run still consumes
  its pending attempt (deleted, as before) so the player retries
  with a fresh `startQuest`, whose `startedAt` excludes the old
  session rec. Verified: `test33.js` §4 16/0/0 — the 0.75 run is
  NOT done and NOT claimable; the 1.0 run completes and claims
  +30 XP; Final Countdown claims +30 XP + 1 💎.
- **B-33-2 (PRODUCT BUG — en33 merge lost regionClaimed, found by
  `test33.js` §8):** the first merge draft used
  `unionTrue(l33.regionClaimed, c33.regionClaimed)` in
  `src/v20_sync.js`. `unionTrue` (pre-existing V20 helper) is
  local-priority last-writer-wins per key — it copies cloud first,
  then local overwrites — so a local `{ko:0}` overwrote a cloud
  `{ko:1}` and the KO region completion was lost on merge. Its
  other call sites only ever hold 1/absent values, so they are
  unaffected; `unionTrue` itself is unchanged. **FIXED 2026-11-19
  (rebuild, in `build_v33.py`'s replacement text so the rebuild
  applies it):** the en33 branch now unions `regionClaimed` with
  an explicit per-language MAX —
  `{en:Math.max(rcL.en||0,rcC.en||0),ko:Math.max(rcL.ko||0,rcC.ko||0)}`.
  Verified: `test33.js` §8 26/0/0 — merge of `{en:1,ko:0}` +
  `{en:0,ko:1}` yields `{en:1,ko:1}`; quests/rift/created/pending
  merge, `hasProgress`, validate/export/conflict all pass.
- **Harness bugs found (fixed in `test33.js` only, no game file
  touched):**
  - D-33-1 (§0): the V18 fall-through check counted a needle that
    also appears in the V19 fight replacement (3× in html, not 2×).
    Fixed to count the V18-specific `bossById` line (×2) plus the
    V19 `D19().byId` line (×1) separately.
  - D-33-2 (§0): `test33.js present in the package under test`
    looked for the harness under `out/tools/v33/`; the harness
    lives in the work tree (`tools/v33/`). Fixed to check `ROOT`.
  - D-33-3 (§1): the open-overlay check ran on a ctx already
    mutated to 71 wins by the sequential-unlock check, so `70/70`
    never appeared. Fixed with a fresh 70-win ctx for the overlay
    checks.
  - D-33-4 (§1/§4): `__v33.isWon` / `regionWon` delegate to
    `__v19.isWon`, which the gate/quest contexts did not load.
    Fixed with a minimal `__v19` stub mirroring the real
    `isWon19`/`stars19`/`en19` semantics (the real UCE path is
    covered in §2 with the real `v19.js`).
  - D-33-5 (§2): the first-win XP check expected only the boss
    reward (165 XP), but the real UCE also pays `mark19` per-answer
    XP (box-up +10 per new word / streak +5), which lands in
    `en15().daily.xp`. Fixed to expect `165 + daily.xp`.
  - D-33-6 (§2): the golem fight was started without winning its
    7 predecessors, so the sequential unlock refused it (`F`
    null). Fixed by granting the 7 predecessor wins first.
  - D-33-7 (§2): the Collection count expected `8/78`, but the
    7 granted wins overlap the sandwisp win (index 0) — true count
    is `7/78`. Fixed the expectation (see §1 run A note).
  - D-33-8 (§4/§7): the quest-context `__v15` stub words carried
    no `lib` (the real `buildWords()` merge sets it), so
    `attachChrono` counted 0; and the `__v19` stub lacked `en19()`,
    so the region-claim title path threw (caught) and the title
    was never pushed. Fixed the stubs to mirror the real
    behaviour; the real merge is covered separately in §7 by
    evaluating the real V33 block from `src/v15.js`.
- **No other game bug found.** The 13 replacements behave as
  specified (gate 69/70, sandwisp fight won through the real UCE,
