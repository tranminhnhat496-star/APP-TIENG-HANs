## 2. Bugs found (all fixed before delivery)

- **B-34-1 — `scopeBlocked()` only fired with a Library scope active.**
  As first built, the blocked bar appeared only when a scope was
  active, so the 12 unfillable bosses showed a `0/3` meter that could
  never fill, with no explanation. Found by the probe's live
  `v11_seadragon` fight (bar showed “💥 Điểm yếu: Động vật — 0/3”
  despite a 390-word pool with 0 weakness words). Fixed in
  `src/v34.js`: `scopeBlocked()` now returns true whenever the fight's
  actual pool holds zero weakness words, scope or not. Fixed via
  restore + re-run (build run 5); probe re-run 106/106 ×3.
- **Build-script bugs (caught by `node --check`, never shipped):**
  `R-V34-V17-LESSON` one `}` too many; `R-V34-V15-CARD` anchor ended
  mid-string-literal. Both fixed in `build_v34.py` with restore +
  re-run.
