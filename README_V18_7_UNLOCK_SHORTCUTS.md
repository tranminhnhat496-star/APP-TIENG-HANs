## What V18.7 adds

### 1. Skyroot shortcut — the road to GEAR GOLEM (`R-V42-V35-GATE`)

- **Before:** the locked Skyroot gate card said only "Thắng GEAR GOLEM bằng ngôn ngữ này để mở vùng đất này." plus the total win count. No hint which boss to fight.
- **Now:** the gate card appends `__v42.skyrootGateHTML(lang, gate)` (`src/v35.js`, one build replacement). When the gate is closed it shows:
  - a button **"⚔️ Đánh \<boss\> ngay — mở đường tới GEAR GOLEM"** naming the first Chrono boss that is unlocked in the current language and not yet won (`skyrootTarget`: walks the 8 Chrono bosses in sequence order via `__v33.bossUnlocked` + `__v33.isWon`, Vietnamese name from `__V33_DATA.byId(id).vi`), plus the sub-line "Thắng \<boss\> bằng \<ngôn ngữ\> để mở boss tiếp theo trên đường tới GEAR GOLEM.";
  - when the next boss IS GEAR GOLEM, the button reads **"⚔️ Đánh GEAR GOLEM ngay"** with "Thắng GEAR GOLEM bằng \<ngôn ngữ\> để mở Thánh Địa Thiên Căn.";
  - when no such boss exists, an honest `<p>` instead of a dead button: "Không tìm thấy boss nào có thể đánh ngay — hãy đóng và mở lại Thánh Địa để cập nhật." (defensive-only — see the viaChrono fallback below, this now means no Chrono boss AND no boss of the 70 is fightable).
  - **while the 70-win Chrono gate is still closed** (e.g. Anh's screenshot state, 13/86 wins): `__v33.bossUnlocked` returns `false` for ALL Chrono bosses, so the sequence scan above finds nothing — `skyrootTarget` then falls back to `chronoTarget(lang)` and returns its result flagged `viaChrono:true`. The button reads **"⚔️ Đánh \<boss\> ngay — mở đường tới GEAR GOLEM"** with "\<boss\> · Lv \<lv\> · boss dễ nhất bạn chưa thắng — thắng trận này (\<ngôn ngữ\>) để lên \<n+1\>/70, mở Vương Quốc Thời Gian rồi đánh bại GEAR GOLEM." — the real next step at 13 wins, not the old false "already won all 8" line.
- **Tap:** `goSkyroot(lang)` re-computes the target at tap time (never trusts the rendered target), closes Skyroot, and either calls `__v33.fightBoss(id)` for a direct Chrono-sequence target (sets the Chrono language first) — the fight runs through the existing V19 Universal Combat Engine, exactly as if tapped on the Chrono overlay — or, for a `viaChrono` target, launches through the same pool routing as `goChrono` (shared `launchChronoTarget`: V19 → `__v19.setLang(lang)` + `__v19.fight(id)`; V18 → `__v18.fight(id, lang)`; old → `__v15.bossFight(id)`), never through `__v33.fightBoss`, which would refuse a non-Chrono boss while the 70-gate is closed.

### 2. Chrono shortcut — the easiest boss of the 70 (`R-V42-V33-GATE`)

- **Before:** the locked Chrono gate card said "Thắng đủ 70 boss để mở vùng đất này. Không có đường tắt — số liệu là thật, đếm từ chính bản lưu của bạn." The "no shortcut" line is now wrong — the shortcut is the feature — so the copy drops it ("Thắng đủ 70 boss để mở vùng đất này — số liệu là thật, đếm từ chính bản lưu của bạn.").
- **Now:** the gate card appends `__v42.chronoGateHTML(lang, gate)` (`src/v33.js`, one build replacement). When the gate is closed it shows a button **"⚔️ Đánh \<boss\> ngay"** plus "\<boss\> · Lv \<lv\> · boss dễ nhất bạn chưa thắng — thắng trận này (\<ngôn ngữ\>) để lên \<n+1\>/70." (n = `__v33.correctedWinCount()`), or an honest `<p>` when no boss qualifies.
- **How the target is picked (`chronoTarget`):** one list from the three pools that count toward the 70, keeping only unwon + fightable bosses, sorted by Lv ascending with pool tie-break v18, then old, then v19:
  - **old (V15):** only when the language is English — old fights are English-only, so they are never offered in KO mode. Won = `en15().bosses[id].win`; fightable = the V15 sequential rule replicated in V42 (idx 0 always; `king` needs all 9 previous won; otherwise the previous boss won).
  - **v18 (flat V18, en/el/leg):** won = the same mirror as the 70-count (`r.win || r.wins || (r.en && r.en.win) || (r.ko && r.ko.win)`); fightable = `__v18.bossUnlocked(bossObj)`.
  - **v19 (Boss Map):** won = `__v19.isWonAny(id)` — a boss won in EITHER language already counts toward the 70, so winning it again in the current language would NOT advance the count and it is never offered; fightable = `__v19.bossUnlocked(id, lang)`.
- **Tap:** `goChrono(lang)` re-computes the target at tap time, closes Chrono, then launches through the boss's own engine: V19 → `__v19.setLang(lang)` + `__v19.fight(id)`; V18 → opens the English Hub bosses tab first if `#v15body` is missing, then `__v18.fight(id, lang)` (the language passed directly, so the lang-pick screen is skipped); old → opens the bosses tab first if `#v15bossfight` is missing, then `__v15.bossFight(id)`. Returns `true` once a fight is launched (`fight()` itself returns `undefined` — that is not coerced), `false` only on exception / missing layer.

## Fixed in this revision — the Skyroot/70-gate false line (was the flagged known limit)

**Skyroot shortcut no longer shows a false "already won all 8" line while the 70-win Chrono gate is closed.** `__v33.bossUnlocked` returns `false` for all Chrono bosses until 70 wins, so in Anh's screenshot state (13/86 wins) the old `skyrootTarget()` was `null` and the overlay claimed the player had won 8 Chrono bosses — false (0 won, and no Chrono boss fightable yet). Now `skyrootTarget()` falls back to the Chrono shortcut (`viaChrono:true`) while the gate is closed, and `goSkyroot()` launches that target through the shared `launchChronoTarget` pool routing instead of `__v33.fightBoss` (which would refuse it). The null case is now defensive-only with the honest line "Không tìm thấy boss nào có thể đánh ngay — hãy đóng và mở lại Thánh Địa để cập nhật." The Chrono shortcut itself is unchanged.
