## Fixed in this revision — the Skyroot/70-gate false line (was the flagged known limit)

- **Skyroot shortcut no longer shows a false "already won all 8" line while the 70-win Chrono gate is closed.** `__v33.bossUnlocked` returns `false` for all Chrono bosses until 70 wins, so in Anh's screenshot state (13/86 wins) the old `skyrootTarget()` was `null` and the overlay claimed 8 Chrono bosses won — false (0 won). `skyrootTarget()` now falls back to `chronoTarget(lang)` (`viaChrono:true`) while the gate is closed, and `goSkyroot()` launches that target via the shared `launchChronoTarget` routing. The null case is now defensive-only with the honest line "Không tìm thấy boss nào có thể đánh ngay — hãy đóng và mở lại Thánh Địa để cập nhật."
