## Adaptations made during the build (with reasons)
1. **Pet art under `assets/pets/v18/`, not `assets/pets/v15/`** (per the task). `v23.js` hardcodes the `v15/` prefix, so the build extends `stageImg()` / `eggImgHTML()` with a `v18/`-prefix rule instead of moving the art (V33's MOVE decision would have hidden the new art under the old tree). No duplicate bytes.
2. **Wind element added to v23 explicitly.** `PET_ELEMENTS` / `PET_MATERIALS` have no `wind`; without the extension, the Cloud Fox's element chip (`D.elements[sp.el].icon`) would throw and its evolution stone would not exist. Extension of the existing map, documented in the replacements — not a parallel system.
3. **Crystal boss element → cosmic.** No `crystal` key exists in the V19 element map; mapped to cosmic (V33 precedent Time→cosmic), documented in the data-file header and README.
4. **Pet skills defined by the builder.** ChatGPT gave no skill descriptions; skills were defined from each species' theme using existing v23 types only (observable in combat).
5. **No Time Echo / Rift equivalent.** Not in the V18.0 scope — Skyroot ships quests only. `en35` has no rift sub-state; the merge branch mirrors en33 minus rift.
6. **KO-led words stay English-headword records** in the shared store (V33 treatment); no KO deck entries are created. Stated honestly in the Library group note and README, not hidden.
7. **Build script pre-pass added.** `build_v35.py` checks every anchor (src + index.html) before mutating anything, so a missing anchor fails cleanly instead of leaving a half-patched tree (improvement over build_v34, which applied replacements one by one).
8. **One generator bug found and fixed during the build:** `gen_v35_data.py` indexed the weakness-set field at tuple position 16 (gems) instead of 19 — the first generated file had `"key":5` for every boss. Fixed to `b[19]` and regenerated; the build asserts 2 bosses per set.

## Fixed (build-time)
- **B-35-1 (generator):** weakness table emitted `"key":5` (gems index) — fixed to the set slug, regenerated, verified 8 entries / 2 per set.
- **B-35-2 (SEVERE, found in testing 2026-11-19):** `bossUnlocked19()` in `v19.js` looked up `D19/V33` only — no `__V35_DATA` fall-through — so the Skyroot unlock delegation was unreachable dead code and NO `v18_*` boss could ever be fought (`fight()` refused every Skyroot boss, overlay button included). Fixed by `tools/v35/fix_b35.py` (byte-exact, `src/v19.js` + inlined block in `out/index.html`); verified live in Chrome (Lynx fight, HP 760 → Break bar fills, boss damage lands). Root-cause fix also applied to `build_v35.py` (`R-V35-V19-UNLOCK-LOOKUP`, 2026-11-19) so a from-scratch rebuild reproduces the shipped build — verified by `tools/v35/rebuild-proof/rebuild_v35.py` (rebuilt `index.html` BYTE-IDENTICAL to shipped). Related sync: `fix_b35.py` had patched `src/v19.js` but not the standalone `out/v19.js` copy (63 B stale) — re-synced from `src/v19.js`, all 13 src/out copies now agree.
